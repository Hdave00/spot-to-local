# Spot-to-Local

This is a wip TUI program to make it simple, fast, intuitive and convenient for users to download their online playlists, locally. 
It is aimed to unify the flow of saving your music, converting your playlists/tracks/albums as CSVs with metadata using exportify and then downloading them locally for people to enjoy music offline. 
I know its possible to do this already by doing multiple different things togethe from many different plaforms everytime you want to download a new track or song you like, but the point is to make this whole task less tedious (and less daunting for non-tech enthusiasts) and, make this process unified and streamlined in a minimal and fast way. This program will also make it so that you can batch download albums, playlists and liked tracks by just one click. You will also be able to pause and continue where you left off.
Currently I am the only developer for this program, so progress will be slow, but hopefully steady :)
